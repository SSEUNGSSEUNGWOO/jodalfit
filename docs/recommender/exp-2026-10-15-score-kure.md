# 점수표 재보정 — KURE 전환 후 (2026-10-15) · **기각**

KURE-v1 로 바꾸면 유사도 분포가 달라지므로, 2026-10-14 에 OpenAI 기준으로 맞춘 점수표가 더는 안 맞을 것이라 보고 다시 쟀다. **두 안 모두 held-out 에서 떨어져 채택하지 않았다. 현재 점수표를 유지한다.**

## 방법

`--space kure --dump-features` 로 8/1·9/1 두 시점의 특징을 뽑고(`jobs/fit_score_weights.py`), 회사 내 중심화 로지스틱으로 가중치를 적합한 뒤 같은 하네스로 전후를 비교했다. 8/1 로 맞추고 9/1 로 검증. 7/1 은 그 시점 활성 공고의 6.8% 가 `embedding_k` 미생성이라 제외했다(8/1 0.6%, 9/1 1.0% 는 허용).

기준값(현재 점수표, KURE):

| | 8/1 | 9/1 |
|---|---|---|
| final@30 macro | 0.490 | 0.467 |
| mrr | 0.188 | 0.241 |

## 안 1 — 회귀가 제안한 전체 묶음

| 항목 | 현재 | 적합값 |
|---|---|---|
| 재출현 기관 | +40 | +10 |
| 지역 매칭 | +30 | +20 |
| 업종·물품 토큰 | 10/개 | 5/개 |
| 예산대 | +5 | 0 |
| 예산 괴리 | −5 | 0 |
| 고정 거래처 | −10 | 0 |

결과: 맞춘 시점 r5 0.431 → 0.493, **검증 시점 r5 0.556 → 0.521, mrr 0.426 → 0.370**, cold 군도 하락. 전형적인 과적합. 기각.

## 안 2 — 가장 강한 둘만 (재출현 기관 40→10, 지역 30→20)

전체 묶음이 과적합이라면 lift 가 가장 확실한 두 개만 줄여 보는 것이 다음 가설이었다(lift: 기관 17.4, 지역 21.1).

| final@30 | 8/1 전 → 후 | 9/1 전 → 후 |
|---|---|---|
| 전체 | 0.490 → **0.484** | 0.467 → 0.473 |
| cold | 0.445 → 0.445 | 0.311 → 0.311 |
| rich | 0.528 → **0.518** | 0.575 → 0.600 |
| small | 0.490 → 0.490 | 0.455 → **0.445** |
| 용역 | 0.462 → **0.455** | 0.446 → **0.441** |
| 공사 | 0.624 → 0.624 | 0.542 → 0.561 |
| 물품 | 0.323 → 0.323 | 0.358 → 0.358 |

8/1 은 전체가 내리고 9/1 은 오른다. rich 는 시점마다 부호가 반대다. 용역만 두 시점 모두 내린다. **방향이 일정하지 않아 잡음과 구분되지 않는다.** 채택 기준("두 시점 모두 상승, 어느 군도 하락 없음")을 못 넘겼다. 기각.

## 남은 것 — "등록업종 허용"이 음수로 나오는 문제

안 1 에서 `has_allowed`(공고가 회사 등록업종을 허용)가 **−10** 으로 적합됐다. P(pos|on) 0.0046 < P(pos|off) 0.0054, lift 0.85. 상식과 반대다.

가설: 2026-10-14 에 넣은 업종 채널이 "업종은 허용하지만 내용은 안 맞는" 공고를 후보에 대량 투입한다. 후보 풀 안에서 보면 업종 허용은 변별력이 없고 오히려 잡음이 된다. 즉 업종이 나쁜 게 아니라 **후보 구성이 바뀐 탓에 생긴 착시**일 가능성이 크다.

확인 방법: 후보를 유입 채널(dense / 업종)로 나눠 각각 안에서 `has_allowed` lift 를 재면 구분된다. 지금 하네스는 채널을 기록하지 않으므로 그것부터 필요하다.

## 결론

- **현재 점수표 유지.** `app/recommender/score.py` 변경 없음.
- 다음 시도 전에 필요한 것: (1) KURE 백필 완료 후 7/1 시점 복구 → 검증 시점 2개 확보, (2) 표본 확대(8/1 n=178, 9/1 n=150 은 11개 항목을 적합하기엔 얇다), (3) 후보 유입 채널 기록.
- 점수표보다 큰 병목은 여전히 후보 검색이다. 8/1 기준 정답 손실 80건이 후보 진입 실패, 점수 탈락은 33건. 물품군 dense 회수율 0.46 이 가장 낮다.
