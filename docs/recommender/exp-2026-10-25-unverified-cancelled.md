## 발단 — 유원디자인연구소 (2026-10-25, 운영 데이터)

네이버 유입 상위 검색어인 회사. 나라장터 등록업종 0 · 공급물품 0 · 계약 이력은 있음(벡터 있음).

- 20건 중 **15건이 "면허 확인불가"로 통과** — 궤도회로 케이블 개량 공사(전기공사업), 건축공사, 건설폐기물 처리업 공고까지. `qualifications.py` 가 회사 업종이 비면 unverified 로 통과시키고 감점 0 이었다.
- 11번·13번이 같은 공사 — 13번(R26BK01773219)은 001차수가 **취소공고**인 원공고, 11번은 새 번호로 재발주된 것. 코드 어디에도 취소 처리가 없었다.
- 1번·16번은 공고가 업종제한 Y 인데 `bid_license_limits` 행이 없어 "면허 제한 없음"으로 판정.

## 고친 것

1. **취소공고 제외** — `app/recommender/cancellation.py`. `rank_v2` 가 자격 조회와 병렬로 후보 공고번호의 모든 차수·상태를 읽어(300개 번호 363ms, 병렬이라 응답 시간 증가 없음) 취소된 (번호, 차수)를 뺀다. 하네스도 같은 함수로 재생(`fetch_cancel_map`, t 이전 게시분만).
2. **면허 확인불가 감점** — `UNVERIFIED_LICENSE_PENALTY = 12`. 회사 등록업종이 비어 판정 못 한 경우(`license_unknown == "company"`)만. 값은 가장 센 보너스 하나(재출현 기관 +12)와 같은 크기 — 채점표 표본(낙찰 이력 회사)에 업종 0건 회사가 1~6곳뿐이라 **값은 측정이 아니라 판단**이다.
3. **면허 행 없음 + 허용업종 원문 있음 → "확인불가"** 라벨(감점 없음). 전엔 "제한 없음"이었다.
4. 응답 `company.industry_count`, 결과 화면에 "나라장터에 등록업종이 없어 면허 자격을 판정하지 못했습니다. 면허 제한이 있는 공고는 순서를 낮췄습니다." 한 줄.

## 측정 — 3,000곳 · seed 7 · pool 200 · hybrid+prd

"전"은 같은 날 DB 로 다시 돌렸다(`--keep-cancelled --no-license-text --unverified-penalty 0`). 10-23 기준점과 비교하면 이틀치 낙찰 데이터 증가(2,027 → 2,044곳)가 섞인다.

세 시점 모두 전 군이 같거나 오르고 떨어진 군이 없다. 자격 통과율(r_qual)은 변화 없음 — 취소공고는 정답(낙찰)이 될 수 없고, 확인불가는 통과를 유지하므로 예상대로. 효과는 "점수 순위에 밀린 정답"이 줄어드는 것(7/1 191 → 185, 8/1 263 → 257, 9/1 144 → 140): 취소공고가 차지하던 자리를 정답이 채운다.

**10/1 시험(조정에 쓰지 않은 시점, 1,255곳):** final@20 0.666 → 0.666(동률), final@5 0.534 → 0.542, MRR 0.375 → 0.382 — cold·small·rich MRR 전부 +. small final@20 −0.002(510곳 중 1곳), 용역 −0.001 은 잡음. 과적합 징후 없음 → **채택.**
업종 0건 회사 3곳 중 1곳은 감점 때문에 정답이 20위 밖으로 밀렸다(1.000 → 0.667). 표본 셋이라 판단 근거는 못 되지만, 이 감점의 비용이 어디서 나는지는 보여준다 — 업종은 없어도 실제로 면허 제한 공고를 낙찰한 회사가 있다. 값 12 는 그래서 "제외"가 아니라 "뒤로"다.

## 해 보고 뺀 것

**공고 쪽 면허 행 없음에도 −12.** 처음엔 "면허 확인불가"면 회사·공고 어느 쪽 이유든 감점했다. 8/1 에서 final@20 −0.030, 공사 −0.080, cold −0.037 로 무너졌다. 원인은 8/1 시점 공고의 **46%** 가 면허 행이 없었던 것(8월 `ingest_license_limit` 공백) — 정답 공고까지 −12 를 먹었다. 그건 회사가 아니라 우리 자료의 구멍이라 감점 대상이 아니다. 라벨만 확인불가로 두고 감점은 회사 쪽으로만 좁혔더니 8/1 이 +0.009 로 돌아섰다. 9/1(1.2%)에선 둘의 차이가 안 보였다 — 한 시점만 보면 못 잡았을 결함이다.
