# 후보 검색 물품 채널 (2026-10-15) · **채택**

업종 채널(0044, [exp-2026-10-14-retrieval.md](exp-2026-10-14-retrieval.md))과 같은 구조로 **물품분류번호 채널**을 더했다. 회사 공급물품 코드(`company_supply_products.dtl_prdct_clsfc_no`)를 하나라도 가진 공고(`bid_notices.prdct_clsfc_nos`, 0047) 안에서 유사도 검색한 결과를 dense·업종 채널과 번갈아 합친다.

## 왜

8/1 기준 정답 손실 175건 중 80건이 후보 진입 실패였고, 물품군 dense 회수율이 0.46 으로 가장 낮았다. 표준 API 에는 물품분류번호가 없어 상세 API(BidPublicInfoService)로 물품 공고만 다시 긁어 채운 뒤(5~10월 100%), 놓친 물품 낙찰 중 코드가 겹치는 비율을 쟀다(`jobs/probe_prdct_channel.py`):

| 시점 | 놓친 물품 낙찰 | 코드 겹침 | 공급물품 있는 회사만 |
|---|---|---|---|
| 7/1 | 44 | 43% | 63% |
| 8/1 | 49 | 55% | 82% |
| 9/1 | 43 | 21% | 90% (43건 중 33건은 회사에 공급물품 미등록) |

업종 채널의 근거였던 56% 와 같은 수준. 효과는 회사 풍부화 커버리지(공급물품 등록 여부)에 묶인다.

## 결과 (현재 운영 = hybrid 2채널 + 점수표 ×0.3 → hybrid+prd 3채널)

| final@30 | 7/1 | 8/1 | 9/1 |
|---|---|---|---|
| 전체 | 0.358 → 0.361 | 0.484 → **0.496** | 0.480 → 0.484 |
| 물품 | 0.264 → **0.282** | 0.331 → **0.403** | 0.346 → **0.384** |
| 공사 | 0.364 → 0.364 | 0.614 → 0.604 | 0.551 → 0.542 |
| 용역 | 0.393 → 0.393 | 0.459 → 0.459 | 0.475 → 0.475 |
| cold / small / rich | = / +0.010 / = | +0.010 / +0.020 / +0.005 | = / = / +0.010 |

물품 dense 회수율: 0.545→0.654 / 0.460→**0.677** / 0.440→0.553. mrr 은 세 시점 모두 같거나 상승.

**공사 −0.01(8/1·9/1)** 은 채널이 셋이 되며 dense 몫이 1/2→1/3 로 준 비용이다. 공사 회사도 공급물품 코드를 갖는 경우가 있어 물품 채널이 끼어든다. 군당 100곳이라 한 곳 차이.

## 기각한 변형 — 중첩 합치기

물품 채널을 업종 채널과 한 자리에 두고(`rr(rr(prd, ind), dense)`) dense 몫을 1/2 로 지키는 안. 9/1 만 완주했고(7/1·8/1 은 네트워크 단절로 중단) **전부 나빠졌다**: 전체 0.480→0.457, rich 0.595→0.535, 공사 0.551→0.509, 물품도 0.346→0.340. 업종 몫이 1/4 로 줄어드는 손해가 물품 채널 이득보다 크다. 업종 채널은 건드리면 안 된다.

## 운영 적용

- 0047(컬럼)·0048(RPC `product_codes`) DB 적용됨. `recommend.py::_search_with_embedding` 이 `_fetch_company_terms` 에서 코드를 받아 세 번째 채널로 보낸다. 코드 없는 회사는 종전 2채널 그대로. 0048 미적용이면 `_PRODUCT_CHANNEL` 1회성 off.
- `hourly-sync.yml` 에 물품 상세 수집 스텝(최근 2일, `--fill`) 추가 — 새 공고에도 코드가 붙는다. `DATABASE_URL` 필요.
- 하네스 `--retrieval hybrid+prd`. 전후 비교 run: `k03-07/08/0901` vs `prd-07/08/0901`.
- 롤백: `RECO_RETRIEVAL=dense` 는 두 채널 다 끄고, 물품만 끄려면 `_PRODUCT_CHANNEL = False`.
