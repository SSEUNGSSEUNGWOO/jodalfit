# 실험: 첨부문서 인사이트 모델 비교 — gpt-4o-mini vs claude-haiku-4-5 (2026-10-15)

공고 페이지의 "참가 조건·과업·평가" 블록은 `summarize_bid_documents` 가 첨부문서에서 뽑은 인사이트로 채운다. 지금까지 gpt-4o-mini 였고 정확도를 잰 적이 없었다. Anthropic 크레딧(Max, 월 $200)이 생겨 비교했다.

## 방법
- 진행 중 공고 40건(용역 14·공사 13·물품 13, 수의계약 제외, 무작위). 입력은 운영과 동일(`build_input`, ≤1.2만 자).
- 같은 SYSTEM 프롬프트·JSON 스키마. OpenAI 는 json_schema, Anthropic 은 tool_use 로 강제.
- 채점: claude-sonnet-5 가 **원문을 보고** 두 결과(A/B 무작위)를 대조 — 필수조건 누락 수, 지어낸 조건 수, 숫자 오류 수, 요약·범위 품질(1~5), 승자. 스크립트: 세션 임시(`llm_compare.py`, `rejudge.py`).

예: 폐기물 처리용역 — 4o-mini 는 "수집·운반 실적 4,300만 원 이상, 낙찰하한율 87.745%, 종합평점 95점" 을 통째로 빠뜨림. Haiku 는 전부 잡음. Haiku 가 지어낸 조건이 5건 더 많은 것은 "더 많이 뽑는" 대가(대부분 결격사유를 조건으로 표현한 류).

## 비용
한국어는 Anthropic 토크나이저에서 토큰이 1.6배 나온다. 공고당 입력 1.3만 + 출력 0.9천 토큰 → 정가 약 25원, Message Batches(50%) 약 12원. 경쟁입찰 전부(~490건/일) 돌리면 월 9만 원 안팎 — 크레딧 안. 절 단위 입력으로 줄이면 절반.

## 결정
- 전환: `INSIGHT_PROVIDER=anthropic` 기본, Haiku 4.5, Message Batches. 롤백은 `openai`.
- 후속: ☐ 커버리지 100%(진행 중 경쟁입찰 전부 — 2026-10-15 `--limit` 이 500 단위 배치 여러 개를 제출하게 바꿔 길이 열림), ☑ xlsx 규격서 읽기(zip 전개 포함), ☑ 마감 지난 문서 텍스트 비우기(`purge_expired_documents`, 1.6GB → 481MB), ☐ 절 단위 입력.
- 임베딩은 그대로 OpenAI (Anthropic 은 임베딩 모델 없음).
