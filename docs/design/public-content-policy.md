# 사이트 공개 안내 기준

2026-10-28 결정. GitHub 저장소 PUBLIC과 GitHub Actions 운영은 유지한다. 아래는 사이트의 공개 안내 범위이며, 저장소 문서나 코드가 비공개가 되었다는 의미가 아니다.

- `/changelog`는 `frontend/src/lib/changelog.ts`의 `PUBLIC_CHANGES`에 공개용으로 편집한 항목만 표시한다. `docs/recommender/changelog.md` 등 실험 기록을 읽거나 자동 변환하지 않는다. 일부 제목만 숨기는 방식은 사용하지 않는다.
- 공개 글은 기능 변화·사용자 이점·수정한 문제와 이용상 한계를 설명한다. 내부 가중치·임계값·모델·인프라·실험 지표·개별 사용자 행동·미출시 계획은 포함하지 않는다.
- `/about`과 `/faq`의 추천 설명도 같은 원칙을 따른다. 회사별 추천 이유·자격 확인불가 표시와 공고 원문 확인 안내는 유지한다.
- 과거 실험 수치를 현재 성능으로 오해하게 하는 '지금' 성적표와, 내부 글을 몇 건 숨겼다는 안내는 사이트에서 제거한다. 공개 기능 변경에 해당하는 내용만 검토 후 수동으로 추가한다.
- `llms.txt` 등의 사이트 소개도 공개 안내 내용과 일치시킨다.

검증: `frontend/scripts/check_changelog.py`는 명시적 공개 목록과 화면을 대조하고, 개선 기록·소개·FAQ의 본문 및 전달 HTML에 내부 설명이 남지 않았는지 확인한다. `check_about.py`는 추천 기준과 한계 안내가 유지되는지 확인한다.
