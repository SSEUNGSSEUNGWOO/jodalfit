# 2026-10-28 추천 접근성과 화면 길이 개선

- 회사 상세 상단에 "이 회사 기준 추천 공고 N건"과 아래 추천 판으로 이동하는 링크를 추가했다. 수주 이력을 먼저 주는 기존 판 순서·자기 회사 검색 다리·SEO 메타·JSON-LD는 유지한다. 폐업 회사와 벡터 없는 회사에는 이 바로가기를 표시하지 않는다. 추천 수를 못 읽으면 숫자를 생략하고 이동 링크는 남긴다.
- 상단 건수와 하단 추천은 React `cache`로 요청당 같은 결과를 공유해 추천 API를 두 번 호출하지 않는다. 상단 바로가기는 Suspense로 감싸 느린 추천 조회 중에도 일반 이동 링크를 보여준다.
- 결과 화면의 사전규격과 발주계획을 독립된 접기 영역으로 나눴다. 의견 접수 중인 사전규격은 기존처럼 처음부터 펼친다. 발주계획은 기본 3건만 보이며 더 보기·3건만 보기·전체 접기를 제공한다.
- 비로그인에게 공개하는 상위 5건은 유지하고, 가입 구간 뒤의 흐린 미리보기는 3건에서 1건으로 줄였다. 무료 가입의 이점을 "전체 공고 확인·검토할 공고 보관"으로 명시하고 버튼은 "무료 가입"으로 바꿨다. 인증 뒤 복귀 URL과 미리보기의 inert 처리는 유지한다.

검증: `check_design_refinements.py`는 모의 스트림으로 공개 5건·미리보기 1건·가입 복귀 URL·발주계획 3/전체·두 영역 독립 접기와 1280/390 가로 넘침을 확인한다. `check_company.py`는 실제 회사 페이지의 상단 바로가기 위치와 추천 판 이동도 확인한다. 기존 저장 버튼 검증과 타입 검사·lint·production build를 함께 실행한다.
