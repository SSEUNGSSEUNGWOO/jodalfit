# 조달핏 브랜드 자산

결정 2026-10-16 (승우님) — 마크 **ㄱㄴ 틀 "찰칵"**: 갈고리 둘(ㄱ 오른 위·ㄴ 왼 아래)이 비껴 마주 보며 네모를 틀 짓는다. 두 손으로 만든 사진 틀 — 골라서 담는다. 시안·조정 격자·모션은 `../prototypes/logo-final.html`.

마크 기하(64 기준): `M30 14 H50 V34 M14 30 V50 H34`, 획 11, 끝·모서리 둥글게. 바깥 네모 14~50, 두 갈고리 사이 틈 5(= 획의 절반). 이 틈이 자르기(crop) 아이콘과 갈라놓는 전부다 — 줄이지 않는다.

## 색
- 주황 `#f97316` · 먹 `#141414` · 종이 `#faf9f7` · 흰 `#fff`.
- **주황은 선이지 면이 아니다.** 사이트 전체 규칙(`../README.md`). 유일한 예외가 **로고 타일**: 주황 면 위 흰 마크. 로고는 글자 대비 규칙 대상이 아니라서다. 버튼·배지·칩에 이 예외를 끌어다 쓰지 않는다.
- 쓸 수 있는 조합 다섯: 주황 타일+흰 / 먹 타일+흰 / 흰 타일(헤어라인 `#e3e1dc`)+주황 / 타일 없이 주황 / 타일 없이 먹.

## 크기·여백
- 최소: 타일 16px(`favicon.svg`), 타일 없는 마크 18px(nav). 그 아래로는 쓰지 않는다.
- 여백(clear space): 마크 사방에 **획 굵기 하나**(64 기준 11 = 마크 폭의 약 1/4). 타일은 타일 자체가 여백이라 타일 바깥에 획 하나.
- 워드마크: Pretendard 800, 자간 −0.035em. 타일 높이의 약 73%(타일 22 → 글자 16px). 700 은 타일 옆에서 가늘어 보여 쓰지 않는다.

## 하지 말 것
- 회전·기울임 없음(두 갈고리의 대각이 뜻이다). 좌우 반전 없음.
- 그라데이션·그림자·외곽선 없음. 주황·먹·흰 외 색 없음.
- **타일 없는 마크를 주황 바탕에 올리지 않는다** — 주황 위엔 타일(흰 마크)만.
- 마크를 다른 아이콘·글자와 한 덩어리로 합치지 않는다. 틈 5 를 메우지 않는다(crop 이 된다).
- 흰 타일 버전은 헤어라인을 뺀 채 흰 바탕에 올리지 않는다(사라진다).

## 모션 "찰칵" (후보)
두 갈고리가 바깥으로 20%(64 기준 8) 벌어진 채 시작해 **260ms, `cubic-bezier(.3,.7,.2,1)`** 로 맞물리고, 94% 에서 0.6 안쪽까지 들어갔다 마지막 한 프레임에 제자리. 결과 페이지 머리(계산 대기)의 로딩·전환 모션 후보. `prefers-reduced-motion` 이면 정지. 데모는 `../prototypes/logo-final.html` 맨 아래.
